The core merging logic is defined in backend/reconcile.py. For each MPGV record (v), the system searches for
Skjálftalísa records (s) that satisfy all three conditions:
    |t_v − t_s| < 3 seconds
    dist_km((lat_v,lon_v),(lat_s,lon_s)) < 5 km
    |Mw_v − Mw_s| < 1.0
If exactly one matching Skjálftalísa record is found, the system replaces the MPGV location with Skjálftalísa's
location and depth. Otherwise, the event remains as v_only.
