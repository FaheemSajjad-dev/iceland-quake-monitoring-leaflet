# Declaration of AI-Assisted Work

Generative AI tools, including Anthropic Claude Sonnet 4.6,
Claude Opus 4.6, and OpenAI Codex, were used as development
and review aids during selected parts of this project.

Their use included reviewing and revising documentation and
comments, assisting with selected frontend, performance,
security, and earthquake-reconciliation changes, reviewing
the repository for consistency and potential security issues,
and preparing the final submission snapshot.

AI-generated suggestions were not accepted automatically.
Each retained change was reviewed, modified where necessary,
and verified through code inspection, frontend linting and
production builds, 77 frontend tests, and 113 passing backend
tests. One backend test requiring a live external service was
skipped.

The system design, selection of data sources, architectural
and implementation decisions, interpretation of results,
evaluation, conclusions, and final submitted work remain the
responsibility of the author.

AI tools were not treated as authoritative academic sources.
Any scholarly facts, methods, or external claims presented in
the thesis are supported by the cited academic or technical
sources.
